Three-Layer Architecture

Error-isolated queries, specialist routing & adversarial stability.

01 · Tree-Query

Coarse-to-Fine Decomposition

Each pair $(X_1, X_2)$ runs $M$ bounded queries—backdoor, independence, latent confounder, direction—avoiding PC/FCI conditioning-set cascades.

$$P_{\mathrm{correct}}(R) \ge 1 - M\exp\!\big(-2m(0.5 - \alpha)^2\big)$$
02 · Clinic & MES

Multi-Expert Routing

A Clinic Agent selects $m$ specialists matched to query $Q$ (graph, statistical, counterfactual, mechanism) and extracts baseline consensus $p_0$.

$$p_0^{\mathrm{raw}} = \frac{\max(N_{\mathrm{yes}}, N_{\mathrm{no}})}{N}, \quad p_0 = 2p_0^{\mathrm{raw}} - 1$$
03 · Proposition 4.6

Adversarial Confidence (ACE)

Three adversarial personas argue for the flipped verdict; Wasserstein-1 shift $|p_j - p_0^{\mathrm{raw}}| = W_1(\hat{\mu}_{\mathrm{ans}}, \hat{\mu}_{\mathrm{adv},j})$ penalizes fragile claims.

$$c = p_0 \left(1 - \sum_{j=1}^{n} \lambda_j \frac{|p_j - p_0^{\mathrm{raw}}|}{p_0^{\mathrm{raw}}}\right)$$

Scope

Data-free causal priors & query budget

Complement, not replacement, for observational data: Tree-Query elicits structured, auditable priors from LLM world knowledge without samples—designed to screen experiments and warm-start downstream statistical learners.

Bounded-reliability premise: Asymptotic identifiability (Theorem 4.1) requires specialist accuracy $1 - \alpha > 0.5$ with approximately independent errors; adversarial multi-persona re-querying trades extra token calls per pair for calibrated stability.
